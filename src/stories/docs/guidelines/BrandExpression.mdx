# Brand expression

Redzone TV is often the first thing people see on the plant floor. It should look like the best software in the building: clean, confident, and current. A display that makes teams proud and makes visitors ask what it is.

Every slide is also a brand display, seen all day by employees, customers, and visitors. The brand frames the data and never competes with it.

**The essentials**

- The brand lives in the footer, never on data.
- Modern comes from Foundations tokens, generous space, and one component for each job.
- Every slide should look like part of the same set as Run Throughput.

## Where the brand lives

| Rule | ID |
| --- | --- |
| The footer is dedicated to the brand. It is a business and commercial requirement, and it never shows data or status. | `BRAND-01` |
| Use the footer tones that exist today, red and blue. The default tone is still to be defined. Do not create new footers per slide. | `BRAND-02` |
| Screens without data can carry more brand: pairing, loading, shift not started, empty states, Company Update, and Welcome. | `BRAND-03` |

## Where the brand does not live

| Rule | ID |
| --- | --- |
| Brand red never appears on data, status, or charts. Negative status has its own color token. | `BRAND-04` |
| No brand color or brand pattern behind numbers. | `BRAND-05` |

## Modern and world class

"Modern" is hard to review, so these rules describe what it means for us.

| Rule | ID |
| --- | --- |
| Use only Foundations tokens for color, type, spacing, radius, and shadow. Nothing is hardcoded. | `BRAND-06` |
| Geist for values people look at, Inter for text people read, always through the type scale roles. | `BRAND-07` |
| Space separates content, not lines. Spacing follows the 4 px scale. No borders around zones. | `BRAND-08` |
| One component for each job. Use an existing component before creating a new one. | `BRAND-09` |
| Icons come only from the Icon component: Material Symbols, Outlined, weight 600. | `BRAND-10` |
| Every slide looks like part of one set. Run Throughput is the reference slide. | `BRAND-11` |

## Light and Dark

| Rule | ID |
| --- | --- |
| Design every slide in Light and Dark. Each screen picks its mode based on the lighting in the plant. | `BRAND-12` |

## Burn-in

Burn-in is a faint permanent shadow that static images leave on some screens. The risk is real on OLED TVs, and low on LCD and LED TVs, which are the most common in commercial displays.

- The footer is the only large static element. Everything else avoids large static, saturated, or high-contrast areas.
- Before investing in prevention, we need to know which screens plants use. If any are OLED, a simple test is to run the slideshow on one TV for 2 to 4 weeks, then show a 50% gray screen and look for marks.

## Checklist

- [ ] The brand appears in the footer and nowhere on data or status.
- [ ] The footer uses an existing tone.
- [ ] Only Foundations tokens are used. Nothing is hardcoded.
- [ ] Geist for values and Inter for text, through the type scale roles.
- [ ] Space separates zones, with no borders.
- [ ] Only existing components and icons are used.
- [ ] The slide looks like part of the same set as Run Throughput, in Light and Dark.

Cada slide también es un display de marca, que ven todo el día empleados, clientes y visitantes. La marca enmarca los datos y nunca compite con ellos.

**Lo esencial**

- La marca vive en el footer, nunca sobre los datos.
- Lo moderno viene de los tokens de Foundations, el espacio generoso y un componente para cada función.
- Cada slide debe verse parte del mismo set que Run Throughput.

| Regla | ID |

## Burn-in

El burn-in es una sombra tenue y permanente que dejan las imágenes fijas en algunas pantallas. El riesgo es real en TVs OLED, y bajo en TVs LCD y LED, que son las más comunes en displays comerciales.

- El footer es el único elemento fijo grande. Todo lo demás evita áreas grandes, fijas, saturadas o de alto contraste.
- Antes de invertir en prevención, necesitamos saber qué pantallas usan las plantas. Si alguna es OLED, una prueba simple es dejar el slideshow en una TV de 2 a 4 semanas, luego mostrar una pantalla gris al 50 % y buscar marcas.
