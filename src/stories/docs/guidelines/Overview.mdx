# Guidelines

Every Redzone TV slide follows three guidelines.

| Guideline | It makes sure that |
| --- | --- |
| [Accessibility](?path=/docs/guidelines-accessibility--docs) | Everyone can read the slide from across the plant floor. |
| [Information design](?path=/docs/guidelines-information-design--docs) | The slide answers one question at a glance. |
| [Brand expression](?path=/docs/guidelines-brand-expression--docs) | The slide looks like Redzone: modern, polished, and on brand. |

## When two guidelines conflict

The higher one wins.

1. Accessibility
2. Information design
3. Brand expression

## How to use them

1. Design the slide from its spec page in **Slides**.
2. Run the checklist at the end of each guideline.
3. In reviews, cite rules by ID, for example "fails INFO-03".

Foundations defines the values (color, type, spacing). Guidelines define how to use them.
