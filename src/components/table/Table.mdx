# Table

## Location table

The shared row layout for multiple location slides (Shift dashboard, Run dashboard, Up/Down stream, Scoreboard, Maintenance status, SPC dashboard). Pending approval.

- Fixed row order (INFO-11). Up to 6 rows per page; add pages instead of shrinking (INFO-09).
- Column headers sit on the sheet: Inter Regular 28 in `text/secondary`, the unit on the same line. The location column has no header by default.
- One row card per location: surface gradient, 1 px `border/subtle`, `radius/lg`, `elevation/card`. Header and rows share one grid, so columns line up. Labels left aligned, numbers right aligned or on a fixed column start.
- Location cell: Geist Medium 32 (card title), wraps to two lines, never cut. Optional detail line in Inter 28 `text/secondary`.
- Plain cells: Geist Medium 32 with tabular figures (A11Y-05). Keep one type scale in a row: no slide title or KPI roles.
- `fill` (default on): rows share the page height between `rowMin` (112) and `rowMax` (184) px.
- Cells render from `cell-<key>` slots with the row as a prop; header cells from `head-<key>` slots.

| Prop | Type | Notes |
| --- | --- | --- |
| `columns` | `{ key, label, width?, align? }[]` | `width` is a CSS grid track. |
| `rows` | `{ id, location, detail?, ... }[]` | |
| `locationLabel`, `locationWidth` | string | Defaults: no label, `minmax(0, 1fr)`. |
| `fill`, `rowMin`, `rowMax` | boolean, number | Defaults: true, 112, 184. |

## Metric cell

The row hero: the one value per row that answers the slide's question. Hierarchy comes from the container, not from a larger font. Pending approval.

- `surface/raised`, `radius/md`, padding 12 / 16. It fills its column, so cells line up.
- Line 1: the row's only status icon (32 px) and the value in Geist SemiBold 32 (chart value, tabular figures). Warning and negative values take `status/{status}/content`.
- Line 2: the target ("Target 80%") in Inter 28, `text/secondary`.
- Place it right after the location name. Other cells stay plain text and neutral unless they need attention.
- Props: `value`, `target`, `status`, `label`.
