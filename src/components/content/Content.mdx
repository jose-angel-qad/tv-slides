# Content

Components for the Other slides (News, Company Update, Welcome). These screens may carry more brand (BRAND-03).

## News item

One alert, chat or high five. Pending approval.

- 72 px tile on `surface/raised` with the type icon: alerts use the warning status icon, chats and high fives outlined content icons in `text/secondary`.
- Meta line in body (Inter 28, `text/secondary`): type in words, author, time. Text in Inter SemiBold 32, wraps, never cut or scrolled (A11Y-15).
- Props: `type` (`alert`, `chat`, `high-five`), `time`, `author`, `text`.

## Media frame

An uploaded image or PDF page, as large as possible (Company Update). Pending approval.

- `object-fit: contain`: the file keeps its aspect ratio, centered, never cropped or stretched.
- Card frame like Chart card (`surface/default`, radius 24, `elevation/card`), with an optional caption row: title on the left, "Page 1 of 3" on the right for a PDF.
- If the file cannot load, it shows the Empty state message with a plain sentence (INFO-21).
- Props: `src`, `alt`, `title`, `page`.
