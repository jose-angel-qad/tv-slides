# Official slide definitions (Redzone Knowledge Base)

Source: "[Info] Preview TV Slides", help.rzsoftware.com/en/articles/9462980-info-preview-tv-slides (February 17, 2026).
This is Redzone's official list of TV slides. Each slide has a one-line definition and an example screenshot of the current product.

Example images are in `docs/agent/kb-examples/` (local only, not in git). They show the current product, which the redesign replaces. Use them to learn what data a slide carries, not how it should look.
